## Key Insights
- Tailwind v4 uses CSS-first configuration via `@theme` directives -- no `tailwind.config.ts` content arrays needed
- `next/font/google` self-hosts fonts (zero external requests, no CLS)
- shadcn/ui components are copied into `components/ui/` (not npm dependency) -- full control
- SSG is the default for pages without server functions in Next.js 15 App Router

## Requirements

### Functional
- Next.js 15 project with App Router
- Tailwind CSS v4 integrated with CSS-first theme config
- shadcn/ui initialized with required components
- Be Vietnam Pro + Open Sans fonts loaded via `next/font/google`
- Project directory structure matching planned architecture

### Non-Functional
- Build time < 10s for initial build
- Zero external font requests at runtime
- TypeScript strict mode enabled
- ESLint configured

## Implementation Steps

### 1. Create Next.js 15 Project
```bash
npx create-next-app@latest ai-employee \
  --typescript \
  --tailwind \
  --eslint \
  --app \
  --src-dir \
  --import-alias "@/*" \
  --turbopack
```
Note: Since project directory already exists, run from inside it or adjust accordingly.

### 2. Verify Tailwind CSS v4
- Confirm `tailwindcss` v4.x in `package.json`
- If v3 was installed, upgrade: `npx @tailwindcss/upgrade`
- Replace `tailwind.config.ts` content arrays with CSS-first `@theme` in `globals.css`

### 3. Initialize shadcn/ui
```bash
npx shadcn@latest init
```
- Style: Default
- Base color: Slate
- CSS variables: Yes
- This creates `components.json` and `src/lib/utils.ts`

### 4. Install Required shadcn/ui Components
```bash
npx shadcn@latest add accordion button card badge tabs
```

### 5. Configure Google Fonts
In `src/app/layout.tsx`:
```typescript
import { Be_Vietnam_Pro, Open_Sans } from "next/font/google";

const beVietnamPro = Be_Vietnam_Pro({
  subsets: ["vietnamese", "latin"],
  weight: ["400", "500", "600", "700", "800"],
  variable: "--font-heading",
  display: "swap",
});

const openSans = Open_Sans({
  subsets: ["vietnamese", "latin"],
  weight: ["400", "500", "600", "700"],
  variable: "--font-body",
  display: "swap",
});
```

### 6. Configure Theme in globals.css
- Add `@theme` directive with project colors and font variables
- Set base styles: `body { font-family: var(--font-body); color: var(--color-text); background: var(--color-background); }`

### 7. Configure next.config.ts
```typescript
const nextConfig = {
  output: "export",  // SSG -- static export if no server needed
  images: {
    unoptimized: true, // Required for static export
  },
};
```
Note: If deploying to Vercel, remove `output: "export"` to use Vercel's image optimization.

### 8. Create Directory Structure
```bash
mkdir -p src/components/sections src/components/shared public/images
```

### 9. Create Placeholder Files
- `src/lib/constants.ts` -- export empty objects
- `src/lib/metadata.ts` -- export empty metadata
- `src/app/page.tsx` -- minimal "Hello World" placeholder

### 10. Verify Build
```bash
npm run build
npm run dev
```

## Risk Assessment
| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Tailwind v4 breaking changes | Low | Medium | Use official upgrade tool, follow v4 docs |
| shadcn/ui + Tailwind v4 incompatibility | Low | High | shadcn/ui supports v4 since late 2025; pin versions |
| Vietnamese font rendering issues | Low | Medium | Test diacritics early; both fonts have verified Vietnamese support |
| Static export limitations | Medium | Low | Only matters for image optimization; use unoptimized or deploy to Vercel |
